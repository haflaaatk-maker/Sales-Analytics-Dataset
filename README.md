# 📊 Sales Analytics Dashboard – Excel

## 📌 Project Overview

This project is an **interactive Sales Analytics Dashboard built in Microsoft Excel** to analyze sales performance, revenue, costs, and profitability across different products, customers, categories, regions, and time periods.

The project uses an Excel-based sales dataset and **Pivot Tables, calculations, and dashboard visualizations** to transform raw sales data into meaningful business insights.

It is designed to help businesses understand **sales trends, product performance, regional performance, customer activity, and profitability** for better data-driven decision-making.

---

## 🎯 Project Objectives

* Analyze overall sales and profit performance
* Track revenue and profitability over time
* Identify top-performing products and customers
* Compare sales performance across regions
* Analyze product/category performance
* Monitor quantity sold and sales volume
* Understand cost versus sales performance
* Identify important sales trends and patterns
* Present business insights through an interactive Excel dashboard

---

## 📂 Dataset Information

The dataset contains **500+ sales records** with the following key fields:

| Column        | Description                        |
| ------------- | ---------------------------------- |
| Order ID      | Unique identifier for each order   |
| Order Date    | Date on which the order was placed |
| Year          | Year of the order                  |
| Customer ID   | Unique customer identifier         |
| Customer Name | Name of the customer               |
| Product ID    | Unique product identifier          |
| Product Name  | Name of the product                |
| Item Category | Product category                   |
| Region        | Sales region                       |
| Quantity Sold | Number of units sold               |
| Unit Price    | Selling price per unit             |
| Cost Amount   | Cost associated with the sale      |
| Sales Amount  | Revenue generated from the sale    |
| Profit        | Profit generated                   |
| Quarter       | Sales quarter                      |
| Month         | Month of the sale                  |
| Month No      | Numerical month value              |
